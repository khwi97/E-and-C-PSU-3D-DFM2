This code is for the paper 'Emulating and Calibrating Antarctic Ice-Sheet Dynamics with Diffusion Models and Deep Feature Matching'.
The folder "Codes" includes the code for the Emulation (DiffusionEmulator.py) and Calibration (mainCalibrationExample.py and mainCalibrationObs.py).
The folder "newdata" includes the data used to train the emulator and the discrepancy weight matrix used for the calibration step.
